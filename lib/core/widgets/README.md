# core/widgets

Reserved for generic, reusable UI components shared across features (buttons,
cards, etc.), per [ARCHITECTURE.md](../../../ARCHITECTURE.md).

This folder is intentionally empty for now. Per
[docs/UI_UX_Principles.md](../../../docs/UI_UX_Principles.md) Section 17
("Consistency Rules"): "Shared patterns are reused, not reinvented" — this is
where those shared components will live once a second feature needs a
component the Dashboard placeholder already introduced. Nothing is added here
speculatively; components move here only once there's a real, second use.
